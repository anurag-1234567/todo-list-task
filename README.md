To-Do Task Manager

Trainee Name:Anurag


=>Project Description

This is a simple To-Do Task Manager created using:

* HTML
* CSS
* Vanilla JavaScript
* Local Storage

The main purpose of this project is to practice JavaScript logic and DOM manipulation.

=>Implemented Features

1. Add a task
2. Display tasks
3. Complete a task
4. Delete a task
5. Edit a task
6. Task counters
7. All / Completed / Pending filters
8. Save tasks using localStorage

 =>JavaScript Concepts Used

* Variables
* Data types
* Functions
* Arrays
* Objects
* map()
* filter()
* find()
* DOM manipulation
* addEventListener()
* Conditional statements
* Template literals
* JSON
* localStorage
* Input validation

 =>Task Object

javascript
{
    id: 1,
    title: "Learn JavaScript",
    completed: false
}


 =>Local Storage

Tasks are stored in localStorage using JSON.

No bonus features were implemented.
